## 1. วิธีเปิดใช้งานหลังแตกไฟล์ `.zip` (สำหรับอาจารย์ผู้ตรวจ)

1. แตกไฟล์ `.zip` แล้วเปิดไฟล์ [index.html](index.html) ด้วย **Google Chrome** หรือ **Microsoft Edge** ได้โดยตรง (**ไม่ต้องติดตั้ง Node.js หรือรันเซิร์ฟเวอร์**)
   - *ทางเลือก:* หากต้องการรันผ่าน Local HTTP Server สามารถใช้ `python -m http.server 8000` ในโฟลเดอร์นี้แล้วเปิด `http://localhost:8000`
2. ระบบมี **คู่มือสำหรับผู้ประเมิน (Evaluation Guide)** อยู่บนหน้าแรก พร้อมปุ่ม **โหลดข้อมูลตัวอย่างครบวงจร** (1 คลิก) และ **แถบสลับบทบาทด่วน** ที่มุมขวาบน (`ลูกค้า` · `พนง. BKK` · `พนง. CNX` · `Admin`)
3. ในหน้ารายละเอียดการจอง (`BK-XXXX`) ระบบจะแสดงกล่อง **"ขั้นตอนถัดไป"** พร้อมปุ่มสลับบทบาทที่ต้องดำเนินการถัดไปให้โดยอัตโนมัติ

### ขั้นตอนทดลองใช้งานแบบ End-to-End (ประมาณ 2 นาที)

1. **ค้นหาและจองรถ (`ลูกค้า`):** ที่หน้าแรก ใช้ฟอร์มค้นหารถ (ค่าเริ่มต้น `BKK → CNX`) กด `ค้นหารถเช่าทันที` → เลือก `ดูราคาและจอง` → กด `ใส่ไฟล์ตัวอย่าง` → กด `ส่งคำขอจอง`
2. **ตรวจเอกสารและอนุมัติ (`พนง. BKK`):** กดปุ่ม `สลับเป็น พนง. BKK` → ติ๊กยืนยันตรวจเอกสาร → กด `อนุมัติคำขอ` (สามารถเปิดเมนู `อีเมลยืนยัน` เพื่อดูอีเมลจำลองได้)
3. **ชำระค่ามัดจำผ่าน QR PromptPay (`ลูกค้า`):** กดปุ่ม `สลับเป็นลูกค้า` → เปิด `ดูใบแจ้งหนี้ ค่ามัดจำ` → กด `จำลองชำระสำเร็จ`
4. **สร้างและลงนามสัญญา 2 ฝ่าย:**
   - สลับเป็น `พนง. BKK` → กด `สร้างสัญญาเช่ารถ` → วาดลายเซ็นหรือพิมพ์ชื่อแล้วกด `ลงนามสัญญา`
   - สลับเป็น `ลูกค้า` → วาดลายเซ็นหรือพิมพ์ชื่อแล้วกด `ลงนามสัญญา`
5. **ส่งมอบรถ (`พนง. BKK`):** สลับเป็น `พนง. BKK` → ตรวจสอบเลขไมล์/ระดับน้ำมัน → กด `ยืนยันส่งมอบและออกใบแจ้งหนี้ค่าเช่า`
6. **รับคืนรถต่างสาขา (`พนง. CNX`):** กดปุ่ม `สลับเป็น พนง. CNX` → ปรับเวลาคืนจริง/ค่าน้ำมัน/ค่าเสียหาย (ระบบคำนวณค่าคืนช้าสด) → กด `ยืนยันรับคืนและออกใบแจ้งหนี้`
7. **ตรวจสอบรายงาน (`Admin`):** กด `Admin` ที่แถบด้านบน → เปิดเมนู `รายงาน` เพื่อดูรายได้แยกสาขา (`BKK` และ `CNX`), Utilization และ Efficiency

## 2. การรัน Automated Tests

โปรเจกต์มีชุดทดสอบอัตโนมัติด้วย Node.js Built-in Test Runner (`node:test`) โดยไม่ต้องติดตั้งแพ็กเกจภายนอก:

```bash
npm test
# หรือ
node --test tests/*.test.js
```

- [tests/model.test.js](tests/model.test.js) — ทดสอบ Business Logic (`TC-01`–`TC-03`, `SMOKE-01`, `SMOKE-02`)
- [tests/ui.test.js](tests/ui.test.js) — ทดสอบ UI Components, XSS escaping, Alignment primitives และทุกหน้าจอในทุกบทบาท

## 3. โครงสร้างไฟล์ในโปรเจกต์

- [index.html](index.html) — หน้าเว็บหลักของระบบ ChaosRoad
- [styles.css](styles.css) — สไตล์ชีต ElevenLabs Editorial Design System รองรับทั้ง Desktop และ Mobile (`390px`)
- [model.js](model.js) — ตรรกะทางธุรกิจ ฐานข้อมูลจำลอง (`D1`–`D8`) กฎการคำนวณราคา/ค่าปรับ และการตรวจสอบสิทธิ์ตามบทบาทและสาขา
- [ui.js](ui.js) — คลัง UI Components และ Formatter (`ChaosRoadUI`)
- [screens.js](screens.js) — หน้าจอทั้งหมดแบ่งตามบทบาท Customer, Staff และ Admin (`ChaosRoadScreens`)
- [app.js](app.js) — ตัวจัดการสถานะหน้าจอ การนำทาง แผ่นวาดลายเซ็น Canvas และระบบจัดการไฟล์ใน `IndexedDB`
- [qr.js](qr.js) — ตัวสร้าง QR Code สำหรับใบแจ้งหนี้ PromptPay
- [REQUIREMENTS.md](REQUIREMENTS.md) — สรุปความต้องการของระบบ (20 FRs, 10 NFRs, 5 Actors, Data Stores `D1`–`D8`)
- [TEST_CASES.md](TEST_CASES.md) — เอกสารกรณีทดสอบ (`TC-01`–`TC-03` และ Smoke Tests)
- [verify.cjs](verify.cjs) — สคริปต์ทดสอบ E2E ผ่าน Playwright (ต้องติดตั้ง `playwright` แยกหากต้องการรันในเบราว์เซอร์จริง)
