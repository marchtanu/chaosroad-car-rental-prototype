## 1. Quick Start (เปิดใช้งานได้ทันที)

1. เปิดไฟล์ [`index.html`](file:///D:/Desktop/Code/university/DST/2nd_year/soft_en_project/ChaosRoad%20Prototype/index.html) ด้วยเบราว์เซอร์ **Microsoft Edge** หรือ **Google Chrome** ได้โดยตรง (ไม่ต้องรันเซิร์ฟเวอร์หรือ Build)
   - *ทางเลือก:* หากต้องการรันผ่าน Local HTTP Server สามารถรัน `python -m http.server 8000` ในโฟลเดอร์นี้แล้วเปิด `http://localhost:8000`
2. **การสลับบทบาทด้วยคลิกเดียว (1-Click Quick Switcher):**
   - ที่แถบด้านบนสุดของหน้าจอ มีปุ่มสลับบัญชีด่วน **`ลูกค้า`**, **`พนง. BKK`**, **`พนง. CNX`**, และ **`Admin`** ซึ่งช่วยให้สลับบทบาทได้ทันทีโดยยังคงหน้าการจองเดิมไว้ (หากบทบาทใหม่มีสิทธิ์เข้าถึงการจองนั้น)
3. **โหมดข้อมูลตัวอย่าง 2 รูปแบบบนหน้าแรก:**
   - **`โหลดข้อมูลตัวอย่างครบวงจร`** — โหลดข้อมูลการจองที่เสร็จสิ้นแล้ว (`BK-0901`), รอการอนุมัติ (`BK-0902`), กำลังเช่าข้ามสาขา (`BK-0903`), ใบแจ้งหนี้ที่ชำระแล้ว, และแผน/ประวัติการซ่อมบำรุง เพื่อให้สำรวจทุกฟีเจอร์ได้ทันทีเหมือนใช้งานระบบจริง
   - **`รีเซ็ตข้อมูลทดลอง`** — ล้างข้อมูลกลับสู่สถานะเริ่มต้นที่สะอาด (`2026-11-10 09:00`) สำหรับรันตามขั้นตอน Test Case (`TC-01` ถึง `TC-03`)

## 2. จุดเด่นของระบบต้นแบบสำหรับผู้ใช้งานจริง (Real-User Usable Features)

- **ค้นหารถได้ทั้งรายประเภทและทุกประเภทรถ (`DFD 2.1–2.2`)** — มีชิปกรองด่วน (`ทุกประเภทรถ`, `Eco Car`, `Sedan`, `SUV`, `SUV 7 ที่นั่ง`, `EV`, `Premium`, `กระบะ`) พร้อมภาพกราฟิกประจำประเภทรถ ป้ายสเปกรถ และสรุปราคาโปรโมชัน + ค่าคืนต่างสาขาอัตโนมัติ
- **สร้างและพรีวิวเอกสารยืนยันตัวตนในหน้าเว็บ (`DFD 2.3–2.4`)** — ลูกค้าสามารถอัปโหลดไฟล์จริง หรือคลิก `ใส่ไฟล์ตัวอย่าง` เพื่อสร้างภาพบัตรประชาชนและใบขับขี่จำลอง พนักงานสาขาสามารถดูพรีวิวภาพบัตรประชาชนและใบขับขี่ได้ทันทีในหน้าตรวจอนุมัติ พร้อมชิปเหตุผลการปฏิเสธด่วน
- **ชำระเงินด้วย QR PromptPay และเลือกบัญชีธนาคาร (`DFD 4.1–4.5`)** — แสดง QR Code เฉพาะของแต่ละใบแจ้งหนี้ รายละเอียดการหักค่ามัดจำ (`DFD 4.2.2`) ตัวเลือกธนาคารผู้ชำระ (`DFD 4.5.2`) ปุ่มจำลองชำระสำเร็จ/ไม่สำเร็จ และปุ่มจำลองเวลาผ่านไป 24 ชั่วโมง (`DFD 4.5.5`)
- **แผ่นวาดลายเซ็นอิเล็กทรอนิกส์ HTML5 Canvas (`DFD 3.1–3.2`)** — รองรับการลากเมาส์หรือนิ้วเพื่อวาดลายเซ็นอิเล็กทรอนิกส์ลงบนสัญญาเช่า (พร้อมบันทึกภาพลายเซ็นลงในใบสัญญา) หรือพิมพ์ชื่อลงนาม
- **ตัวช่วยวัดระดับน้ำมัน `1/8`–`8/8` และคำนวณค่าใช้จ่ายรับคืนรถสด (`DFD 3.3–3.5`)** — มีแถบวัดระดับน้ำมันแบบ 8 ขั้น ตารางเปรียบเทียบข้อมูลตอนส่งมอบกับตอนรับคืนแบบเคียงข้างกัน (Side-by-Side) และคำนวณค่าคืนช้า (ผ่อนผัน 30 นาที ปัดขึ้นรายชั่วโมง สูงสุดไม่เกินค่าเช่า 1 วัน) แบบเรียลไทม์
- **ระบบวางแผนซ่อมบำรุงและรายงานวิเคราะห์ครบตาม DFD (`DFD 5.1–5.4, 6.1–6.3`)** — รองรับการตั้งแผนซ่อมบำรุง (ประเภทงาน, เงื่อนไขระยะทาง/วันเวลา, ความถี่, อู่ที่กำหนด, แจ้งเตือนล่วงหน้า) การบันทึกผลซ่อมบำรุง (อะไหล่ที่เปลี่ยน, อู่ที่ให้บริการ, ค่าใช้จ่าย) และรายงานวิเคราะห์รายได้/อัตราการใช้งานรถ/ประสิทธิภาพการดำเนินงานพร้อมกราฟแท่งเปรียบเทียบ
